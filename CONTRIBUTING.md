# Contribuir

Relate problemas com a versão, o código da carta e um exemplo concreto. Para a aplicação, inclua passos de reprodução, navegador e comportamento esperado. Use personagens fictícios e remova dados privados de capturas e fichas.

Propostas de cartas devem resolver uma lacuna reutilizável e explicar a diferença em relação às existentes. Evite criar uma carta exclusiva para cada personagem ou tratar obstáculos como conflitos internos.

Preserve códigos e textos publicados; mudanças deliberadas exigem versão e notas. O deck aparece em `deck/`, `app/public/` e `skills/persona-cards/references/`: mantenha as três cópias idênticas. Rode os testes de integridade, API e o build antes de propor alterações.

Para UI, preserve acessibilidade, Anime.js, movimento reduzido e funcionamento em desktop e 390 px. Não inclua ambientes virtuais, dependências instaladas, logs ou personagens pessoais no commit.

As discussões e propostas podem ser feitas por issues e pull requests. O projeto ainda não tem licença de redistribuição definida.
